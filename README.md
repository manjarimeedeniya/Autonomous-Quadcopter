# Autonomous-Quadcopter
An autonomous drone system engineered for multi-waypoint navigation, obstacle avoidance, and visual marker detection.
## Hardware Platform
* **Flight Controller:** Pixhawk (ArduPilot/PX4)
* **Companion Computer:** Raspberry Pi 5
* **Sensors:** GPS, Telemetry, Single-Point LiDAR / Distance Sensors, Downward Pi Camera

## Project Status
> **Note:** Source code, CAD models, ROS 2 packages, and configuration files will be uploaded following our participation in **SLIIT ROBOFEST 2026**.

## Planned Features
* Autonomous waypoint navigation and precision landing
* Multi-directional rangefinder obstacle detection
* Computer vision for visual marker & letter identification
